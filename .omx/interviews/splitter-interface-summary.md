# Local splitter interface interview

## Round 1

Manage a local splitter, remote splitter, or both?

User: Local splitter only; interface manages the splitter on the same computer.

## Round 2

Keep running when the interface closes or stop?

User: Stop the splitter when the interface closes; disconnect all clients.

## Round 3

Automatically connect on launch with saved settings?

User: Yes; first launch shows setup.

## Round 4

Confirm closure during active transmission?

User: Yes; confirmation during TX only, close immediately during RX.

## Round 5

Apply changes requiring reconnect immediately or ask?

User: Save settings, flag reconnect required, ask before applying reconnect.

## Round 6

Remember radio password or prompt each launch?

User: Remember the password locally; hidden in Settings and excluded from diagnostic exports.

## Round 7

Splitter setup/monitoring only, or also radio controls?

User: Setup and monitoring only; existing clients operate the radio.

## Round 8

Session-only statistics or saved history across restarts?

User: Session only, with live graphs covering the last 15 minutes; settings persist.

## Round 9

Normal desktop installation or portable applications?

User: Windows Setup.exe and Start menu shortcut; macOS DMG and drag to Applications; Linux standalone terminal interface.
